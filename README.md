# 🍓 Фотостудия «Малина» — сайт для Белорецка

Готовый сайт фотостудии: красивая главная страница, галерея работ, онлайн-бронирование
с блокировкой занятых слотов, админ-панель для управления фото и заявками.

Ничего устанавливать не нужно — сервер работает на чистом Node.js.

---

## Как запустить

**Способ 1 (самый простой):** двойной щелчок по файлу **`start.bat`**
в папке сайта. Откроется чёрное окно с адресом — и браузер сам откроет сайт.

**Способ 2 (вручную):** откройте терминал в этой папке и выполните:

```
node server.js
```

Сайт будет доступен по адресу: **http://localhost:4321**

Чтобы посмотреть сайт с телефона (в той же Wi-Fi сети) — в окне сервера показан
второй адрес вида `http://192.168.1.106:4321/`, откройте его в браузере телефона.

Окно сервера закрывать нельзя, пока сайт нужен. Остановка — `Ctrl + C` в этом окне.

## Что где находится

### Главная страница (`/`)
* Нежный розовый градиент, который плавно переливается.
* По центру — выбор: **«Я гость»** и **«Я администратор»**.
* Интерактив с курсором: светящийся курсор, след из «ягод», ягоды и сердечки
  разлетаются от курсора, всплеск при клике, наклон карточек за мышью.
  На телефоне то же самое работает от касания пальцем.

### Страница для гостей (`/guest.html`)
* Галерея работ с разделами и просмотром во весь экран.
* Услуги и цены.
* **Бронирование:** гость выбирает формат, дату и время. Регистрация не нужна —
  имя и телефон спрашиваются только при записи.
* **Занятые слоты сразу видны и недоступны.** Как только один гость забронировал
  время, у всех остальных этот слот помечается «занято» — без перезагрузки страницы
  (обновление в реальном времени). Если гость уже выбрал этот час, он получит
  предупреждение и должен выбрать другой.
* Пожелания к съёмке: быстрые кнопки-подсказки + свободное поле.
* «Мои записи» — гость вводит телефон и видит свои брони и их статусы.
* Контакты, карта, ссылки на WhatsApp / Telegram / Instagram / ВК.

### Админ-панель (`/admin.html`)
* **Заявки** — все брони с контактами и пожеланиями, статусы
  (новая → подтверждена → проведена / отменена), заметки, кнопки «Позвонить» и WhatsApp.
* **Фотографии** — загрузка своих фото (перетаскиванием, выбором файлов или
  вставкой из буфера), удаление, подписи, разделы галереи, порядок вывода.
* **Расписание** — видно, какие часы заняты кем, какие свободны; можно закрыть
  время для брони (например, «генеральная уборка») и снова открыть.
* **Гости** — автоматическая база: имя, телефон, число броней, проведённых съёмок.
* **Настройки** — контакты, тексты, услуги и цены, время для брони, смена логина
  и пароля, выгрузка резервной копии данных в файл.

## Фотографии

В галерее лежат **8 картинок-заглушек** (нежные градиенты с подписью
«Замените на своё фото»). Удалите их в панели → «Фотографии» → «Удалить»
и загрузите настоящие кадры.

Все загруженные фото хранятся в папке `data/uploads/`.

---

## Где хранятся данные

| Что | Где |
|---|---|
| Заявки, гости, настройки, фото-подписи | `data/db.json` |
| Сами фотографии | `data/uploads/` |

**Резервная копия:** панель → Настройки → «Скачать резервную копию данных (JSON)».
Достаточно сохранить файл `data/db.json` и папку `data/uploads/` — это все данные сайта.

## Проверка, что всё работает

При запущенном сервере выполните в папке сайта:

```
node tools\smoke-test.js
```

Скрипт проверит страницы, вход админа, загрузку и удаление фото, бронирование,
конфликт двух гостей на один слот, блокировку времени, смену пароля и сам уберёт
за собой тестовые данные.

## Мелочи, которые полезно знать

* Брони гостей **без предоплаты** — оплата на месте (текст можно изменить в настройках).
* Пароль администратора хранится в виде зашифрованного хеша, сессия входа — 12 часов.
* После 8 неудачных попыток входа панель блокирует попытки с этого компьютера на 10 минут.
* Сайт помечен как `noindex` для поисковиков, если позже захотите продвигать
  сайт в интернете — уберите строку `<meta name="robots" content="noindex, nofollow">`
  из `public/admin.html`.
* Сайт адаптирован под телефоны, планшеты и компьютеры.
